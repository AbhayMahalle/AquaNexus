## Documentation Standards

### Writing Guidelines

- **Clarity:** Use clear, concise language
- **Completeness:** Include all relevant details
- **Examples:** Provide concrete examples where applicable
- **Diagrams:** Use ASCII art, Mermaid, or images for visualization
- **Updates:** Keep documentation in sync with implementation
- **Cross-references:** Link to related documentation

### Markdown Format

- Use headings for structure
- Use code blocks with language specification
- Include tables for comparisons
- Use bullet points for lists
- Include mermaid diagrams for complex flows
- Link to related documents

### Diagram Tools

- **Mermaid:** Flowcharts, sequence diagrams, ERD
- **ASCII Art:** Simple diagrams and tables
- **External Tools:** Draw.io, Lucidchart (export as images)
