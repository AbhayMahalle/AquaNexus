# AquaNexus — Water Plant Management System (Frontend)

Enterprise ERP frontend built with **React**, **Vite**, **TypeScript**, **Tailwind CSS**, and **Lucide Icons**.

## Responsibilities & Modules (Yash - Frontend Member 4)
- **Distributor Frontend**: `/distributor/*` (Dashboard, Products, Orders, Stock, Sales, Returns, Invoices, Payments, Outstanding)
- **Accountant Frontend**: `/accountant/*` (Dashboard, Payroll, Payments, Expenses, Outstanding, Reports)

## Quick Start
```bash
npm install
npm run dev
```

App runs locally on `http://localhost:3000`.
